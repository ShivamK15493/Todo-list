# 📝 Todo List App

An interactive **Todo List Web Application** built using **HTML, CSS, and Vanilla JavaScript**. The application allows users to add tasks, view the total number of tasks, and delete tasks when they are completed or no longer needed.

## 🚀 Features

* ➕ Add new tasks
* 🗑️ Delete individual tasks
* 🔢 Display total number of tasks
* ⚡ Dynamically create tasks using JavaScript
* 🖱️ Handle user interactions with event listeners
* 🎨 Simple and clean user interface
* 📱 Basic responsive layout using CSS Flexbox
* 🚫 No external libraries or frameworks required

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the application.
* **CSS3** – Used for styling, layout, buttons, task cards, and overall appearance.
* **JavaScript** – Used for DOM manipulation, task creation, deletion, counting, and event handling.

## 🎯 Purpose

The purpose of this project is to create an interactive task management application that helps users organize their daily tasks efficiently. It also demonstrates the practical use of **HTML, CSS, and JavaScript** for creating dynamic web applications with DOM manipulation and event handling.

## 🏁 Conclusion

The Todo List App is a simple project that demonstrates how **HTML, CSS, and Vanilla JavaScript** can be combined to build an interactive web application. It provides essential task management functionality while helping develop practical knowledge of **DOM manipulation, event handling, dynamic elements, and responsive design**.
